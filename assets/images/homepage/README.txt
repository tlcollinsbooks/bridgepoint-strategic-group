# Overview

This repository contains the official corporate website for **BridgePoint Strategic Group**, a bilingual (English / Spanish) website representing the BridgePoint business ecosystem operating in Panama.

The website has been designed to present BridgePoint as a premium, professional organization while providing visitors with clear information about its divisions, projects, strategic partners, and services.

---

# Divisions

The website includes the following divisions:

- BridgePoint Strategic
- BridgePoint Development Management
- BridgeWork Solutions
- BridgePoint Infrastructure
- Azuero Capital Advisory
